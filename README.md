# omarchy-ru

Разворачивает русскую Omarchy с обновлённым шелл-окружением на чистой машине —
или догоняет уже настроенную до того же состояния.

```bash
git clone <репозиторий> ~/Projects/omarchy-ru
cd ~/Projects/omarchy-ru
./install.sh
```

Скрипт запускается **от обычного пользователя**; `sudo` он попросит сам в тех
двух местах, где это нужно (локаль и установка пакетов).

## Что делает

| Модуль | Что ставит и куда |
|---|---|
| `omarchy` | Проверяет, что это Omarchy 4 (Quattro). На версии старее запускает `omarchy update` и проверяет снова |
| `locale` | Собирает `ru_RU.UTF-8`, ставит системный `LANG` |
| `keyboard` | Раскладка `us,ru` по Alt+Shift в `~/.config/hypr/input.lua` плюс демон `hypr-sync-kb-layout` |
| `menu` | Русские подписи меню Omarchy: генератор, таблица подписей, хук пересборки |
| `packages` | `ghostty`, `atuin`, `yazi`, `git-delta`, `television` |
| `blesh` | Собирает ble.sh из исходников в `~/.local` |
| `bash` | Подключает ble.sh, atuin, television и yazi к `~/.bashrc` |
| `git` | Включает delta как пейджер диффов |
| `terminal` | Делает Ghostty терминалом по умолчанию |
| `theme` | Ставит тему, фон и шрифт из `files/theme.env` |

```bash
./install.sh --list             # список модулей
./install.sh keyboard menu      # только нужные (проверка версии идёт всегда)
./install.sh --dry-run          # показать, что было бы сделано
./install.sh --force            # пересобрать даже то, что уже стоит (ble.sh)
./install.sh --skip-update      # не запускать omarchy update на старой версии
```

## Повторный запуск

Все шаги идемпотентны. Правки в чужих файлах живут внутри маркеров

```
# >>> omarchy-ru:<блок> >>>
...
# <<< omarchy-ru:<блок> <<<
```

и при повторном запуске заменяются целиком, а не дублируются. Перед каждой
правкой рядом появляется копия `<файл>.bak.<таймстамп>`. Файл, содержимое
которого уже совпадает с эталоном, не трогается вовсе — бэкапы не плодятся.

## После установки

- **Перелогиниться в сессию** — `LANG=ru_RU.UTF-8` подхватят Hyprland, оболочка
  Omarchy и уже запущенные приложения. Оболочку Omarchy держит супервизор,
  запущенный Hyprland'ом со старым окружением, поэтому `omarchy restart shell`
  здесь не помогает.
- **Открыть новый терминал** — ble.sh, atuin и television живут в bash.
  Первый старт молчит пару секунд: ble.sh строит кеши раскладки клавиш.

## Горячие клавиши, которые получаются

| Клавиша | Что делает |
|---|---|
| `Alt+Shift` | Переключение us ↔ ru сразу на всех клавиатурах |
| `Ctrl+R` | Поиск по истории atuin |
| `Ctrl+T` | television: на пустой строке — выбор файлов, на непустой — дополнение слова |
| `Alt+C` | Переход в каталог через fzf (как в стоковой Omarchy) |
| `↑` | Обычная история bash |
| `y` | yazi с переходом в каталог, где вышел |

## Как это настраивать под себя

**Подписи меню.** Правится `files/omarchy/menu-ru.json` (id пункта → `label`
и, если нужно, `title`), потом `./install.sh menu`. Пункты, которых в таблице
нет, остаются в оригинале — так и задумано для имён продуктов вроде Firefox.

Сгенерированный `~/.config/omarchy/extensions/omarchy-menu.jsonc` править
бесполезно, он перезаписывается. Причина, по которой перевод вообще устроен
генератором: оболочка сливает пользовательское меню с упакованным **по полям**
уже нормализованных записей, а нормализация подставляет пустые строки во все
отсутствующие поля. Запись с одним лишь `label` обнуляет пункту иконку,
действие и условие показа, превращая действие в пустое подменю. Поэтому каждая
переведённая строка несёт полную копию оригинала — и эти копии надо
пересобирать после каждого обновления Omarchy. Этим занимается хук
`post-update.d/rebuild-ru-menu`.

**Переключатель раскладки.** Задаётся переменными окружения:

```bash
RU_KB_SWITCH=grp:ctrl_shift_toggle RU_KB_SECOND_LAYOUT=de ./install.sh keyboard
```

Модуль читает текущие `kb_layout` и `kb_options` из живого Hyprland, выкидывает
прежний `grp:*` и добавляет свой, так что чужие опции (`compose:caps` и прочие)
переживают установку. Без запущенного Hyprland берутся значения Omarchy по
умолчанию.

**Тема, фон и шрифт.** Лежат в `files/theme.env`:

```bash
RU_THEME=tokyo-night
RU_THEME_REPO=                      # git-репозиторий, если тема не стоковая
RU_BACKGROUND=0-winding-road.jpg    # имя файла в backgrounds/ темы
RU_FONT=JetBrainsMono Nerd Font
```

Любую переменную можно перебить окружением: `RU_THEME=gruvbox ./install.sh theme`.
Нестоковая тема ставится через `omarchy theme install "$RU_THEME_REPO"`, если
её каталога на машине нет. Пустое значение = «не трогать»: например, пустой
`RU_BACKGROUND` оставит тот фон, который Omarchy выберет сама.

**Шелл-окружение.** Логика лежит в `files/bash/head.sh` и `files/bash/tail.sh`,
которые ставятся в `~/.config/omarchy-ru/bash/`. В самом `~/.bashrc` остаются
только две строки-заглушки, так что менять окружение можно, не трогая rc.

## Чего проект не делает

У Omarchy нет инфраструктуры локализации: ни `qsTr()`, ни `.ts`/`.qm`, ни
gettext. Английскими останутся подписи виджетов бара, OSD, заголовки
уведомлений, вывод команд `omarchy` и описания горячих клавиш в
`omarchy menu keybindings` — они зашиты в код в `/usr/share/omarchy/`, который
перезаписывается при каждом обновлении. Перевести их можно только патчем в
апстрим.

Синхронизация истории atuin между машинами не настраивается — это `atuin
register` / `atuin login` с вашим ключом, дело личное.
